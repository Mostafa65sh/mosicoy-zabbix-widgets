# Changelog

## [1.0.0] — 2026-11-05 — Initial Release

First stable release of **Mosicoy Zabbix Widgets** — 14 widgets for Zabbix 7.0.+

### Added
- Calendar Heatmap, KPI Wallboard, Heatmap Matrix
- Switch Panel, Top Talkers, Interface Errors, Network Map
- Status Grid, Problem Timeline, Sankey Flow, Gauge Cluster
- Radar Compare, Network Topology
- Routing Monitor (preview)

### Features
- 6 color themes
- Dark/light auto-detection
- Responsive, multi-host
- Native Zabbix time period integration

### Fixed
- Auto-refresh white-screen bug
- Widget header not appearing
- CWidgetFieldTextArea crashes in Zabbix 7.0
- Cisco/MikroTik interface parsing
