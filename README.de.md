# Mosicoy Zabbix Widgets

Eine moderne, wunderschöne Widget-Sammlung für Zabbix 7.0 — von einem Netzwerkingenieur, für Netzwerkingenieure.

**Sprachen:** [English](README.md) | Deutsch (diese Datei) | [فارسی](README.fa.md)

## Was ist das?

14 moderne, professionelle Widgets für Zabbix 7.0 — damit deine Dashboards aussehen wie Grafana, Datadog oder moderne NOC-Tools, ohne Zabbix zu verlassen.

Jedes Widget:
- Standardmäßig schön
- Schnell
- Sicher (nie weiße Bildschirme)
- Einfach zu konfigurieren
- Dunkel/Hell-bewusst
- Responsiv

## Warum ich das gebaut habe

Als Netzwerkingenieur, der täglich in NOC-Umgebungen arbeitet, stieß ich immer auf dieselbe Wand: Zabbix ist leistungsstark, aber seine Dashboards sehen aus wie 2010. Also habe ich sie selbst neu gebaut.

## Die 14 Widgets

### Daten und Analyse
- Calendar Heatmap
- KPI Wallboard
- Heatmap Matrix

### Netzwerküberwachung
- Switch Panel
- Top Talkers
- Interface Errors
- Network Map

### Status und Probleme
- Status Grid
- Problem Timeline
- Sankey Flow
- Gauge Cluster

### Vergleich
- Radar Compare
- Network Topology

### Routing (Vorschau)
- Routing Monitor

## Schnellinstallation

1. Release-ZIP herunterladen
2. Nach /usr/share/zabbix/modules/ entpacken
3. In Zabbix: Administration > Allgemein > Module > Verzeichnis scannen
4. Gewünschte Widgets aktivieren

## Farbthemen

6 Paletten pro Widget: Standard, Zabbix, Pastell, Hell, Dunkel, Blau Mono.

## Getestet auf

- Zabbix 7.0 auf Ubuntu 22.04 und 24.04
- Cisco IOS Catalyst
- MikroTik RouterOS
