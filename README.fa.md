# Mosicoy Zabbix Widgets

مجموعه‌ای از ویجت‌های مدرن و زیبا برای Zabbix 7.0 — ساخته شده توسط یک مهندس شبکه، برای مهندسین شبکه.

**زبان‌ها:** [English](README.md) | [Deutsch](README.de.md) | فارسی (این فایل)

## این پروژه چیه؟

۱۴ ویجت مدرن و حرفه‌ای برای Zabbix 7.0 — طراحی شده تا داشبوردهای تو مثل Grafana، Datadog یا NOCهای مدرن به‌نظر برسند، بدون اینکه از Zabbix خارج شی.

هر ویجت:
- زیبا به‌صورت پیش‌فرض
- سریع
- امن (هرگز صفحه سفید نمی‌شود)
- تنظیمات ساده
- تشخیص تم تاریک/روشن
- Responsive

## چرا این رو ساختم؟

به‌عنوان مهندس شبکه که روزانه در محیط‌های NOC کار می‌کند، همیشه به یک دیوار می‌خوردم: Zabbix قدرتمند است، ولی داشبوردهایش شبیه سال ۲۰۱۰ هستند. پس خودم ساختم.

## ویجت‌های ۱۴ گانه

### داده و تحلیل
- Calendar Heatmap
- KPI Wallboard
- Heatmap Matrix

### مانیتورینگ شبکه
- Switch Panel
- Top Talkers
- Interface Errors
- Network Map

### وضعیت و مشکلات
- Status Grid
- Problem Timeline
- Sankey Flow
- Gauge Cluster

### مقایسه
- Radar Compare
- Network Topology

### روتینگ (پیش‌نمایش)
- Routing Monitor

## نصب سریع

۱. فایل ZIP نسخه را دانلود کن
۲. در مسیر /usr/share/zabbix/modules/ استخراج کن
۳. در Zabbix: Administration > General > Modules > Scan directory
۴. ویجت‌های مورد نظر را فعال کن

## تم‌های رنگی

۶ پالت به ازای هر ویجت: پیش‌فرض، Zabbix، Pastel، Bright، Dark، Blue Mono.
